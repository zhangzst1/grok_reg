# JSON 文件合并为 JSONL 设计

## 目标

新增一个独立命令行脚本，把运行命令时当前目录下的所有 `.json` 文件合并为一个 JSON Lines 文件。每个源文件对应输出中的一行，并保证该行是合法 JSON。

## 命令与文件位置

脚本位于 `scripts/merge_json_files.py`，默认用法为：

```text
uv run python scripts/merge_json_files.py
```

默认输出为当前目录下的 `merged.jsonl`。可通过 `-o` 或 `--output` 指定其他输出路径。

## 处理规则

- 仅扫描当前目录，不递归扫描子目录。
- 只读取扩展名为 `.json` 的普通文件。
- 按不区分大小写的文件名顺序处理，保证结果稳定。
- 使用 UTF-8 读取文件，并兼容带 UTF-8 BOM 的输入。
- 解析每个文件后，以紧凑格式重新序列化为单行。
- 使用 UTF-8 写入并保留中文等 Unicode 字符。
- 明确排除输出文件，避免自定义输出名为 `.json` 时被合并。

## 错误处理

如果某个输入文件不是合法 JSON，脚本输出包含文件名的错误信息并以非零状态退出。脚本先写入临时文件，全部处理成功后再替换正式输出，避免留下不完整结果。

如果当前目录没有 `.json` 文件，仍生成一个空的 JSONL 文件，并报告合并数量为零。

## 验证

按用户要求不新增自动化测试。实现后使用临时目录进行一次实际合并检查，并运行项目语法检查。
